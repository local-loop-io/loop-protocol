# Pilot Readiness

City-pilot-outreach readiness artifacts for localLOOP, produced as a solo
maintainer under the process this directory itself establishes. Read in
this order:

1. [SOLO-OPERATOR-ADDENDUM.md](SOLO-OPERATOR-ADDENDUM.md) — the governance
   process this work was reviewed under (enacted by
   [RFC-0005](../../../rfcs/0005-solo-operator-governance-override.md)).
2. [PILOT-USE-CASE.md](PILOT-USE-CASE.md) — the one locked, narrow pilot
   scope: the municipal reuse-depot flow, and why it was chosen over other
   candidates.
3. Reassessed against that locked scope:
   [dpia-lite.md](../../compliance/dpia-lite.md) and
   [threat-model.md](../../compliance/threat-model.md).
4. [PILOT-READINESS-CLAIM.md](PILOT-READINESS-CLAIM.md) — the outward
   claim itself: evidence-backed status per item, explicit non-claims, and
   the self-review checklist applied to it.
5. [PILOT-TERMS.md](PILOT-TERMS.md) — draft pilot terms (not legal advice,
   not ready for signature).

Every claim in this directory expires 2026-09-13 or sooner per
PILOT-READINESS-CLAIM.md's own expiry note — do not treat any of it as
current past that date without re-review.
